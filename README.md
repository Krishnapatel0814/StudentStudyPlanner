📚 Student Study Planner

A simple and user-friendly web application designed to help students organize their study tasks and track their progress.

✨ Features

* ➕ Add study tasks
* 📚 Add subjects
* 🔴 Set task priority
* 📅 Set deadlines
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔍 Search tasks
* 📋 Filter tasks
* 📊 Track study progress
* 💾 Save tasks using browser Local Storage
* 🌙 Dark mode
* 📱 Responsive design

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

📂 Project Structure

```text
StudentStudyPlanner/
│
├── index.html
└── README.md
```

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding your study tasks.

💡 How It Works

The application uses JavaScript to create and manage study tasks.

Each task can contain:

* Task name
* Subject
* Priority
* Deadline
* Completion status

Tasks are saved in the browser using **Local Storage**, so they remain available after refreshing the page.

📊 Progress Tracking

The application automatically calculates the percentage of completed tasks.

```text
Completed Tasks ÷ Total Tasks × 100
```

The result is displayed using a progress percentage and progress bar.
